# Designs

Source for Roomr's visual assets, as in `fonoster/fonoster` and `fonoster/routr`.

| File | What |
| --- | --- |
| `roomr.pen` | The [Pencil](https://pencil.dev) source. Frame "Banner" (1280 x 460) is the design of the README banner. Frame "Banner · LinkedIn" (1200 x 627, square corners) is for social posts: export it from Pencil when you need it; it is not stored in the repo. |
| `../assets/banner.svg` | The animated README banner. Generated by `../.scripts/readme-banner.js` from the "Banner" frame: text is outlined (GitHub shows README SVGs in `<img>`, so no web fonts or scripts) and the motion is CSS keyframes. It respects `prefers-reduced-motion`. |

To regenerate the banner after changing the design:

```sh
npm i opentype.js            # or set OPENTYPE_PATH to its folder
node .scripts/readme-banner.js <fonts dir>
```

The fonts dir needs `Poppins-SemiBold.ttf`, `Poppins-Regular.ttf` and `RobotoMono[wght].ttf`
(OFL, from [google/fonts](https://github.com/google/fonts)). `.scripts/whale-path.txt` is the whale
emoji outlined from Pencil.

The palette is Fonoster's shared component library, GoodTok brand: `#181818` background, `#FF9965`
accent (with `#C46C3F` and `#27150C`), white and gray type. The logo is "roomr" in Poppins
SemiBold with an accent dot, as in Routr. Diagrams in the docs are Mermaid, so they stay text, diff
well and are readable by AI tools; only the banner is an image.
