# Designs

Source for Roomr's visual assets, as in `fonoster/fonoster` and `fonoster/routr`.

| File | What |
| --- | --- |
| `assets/banner.svg` | The README banner (1280 x 460, animated, respects `prefers-reduced-motion`). `../assets/banner.svg` is the copy the README uses; keep them identical. |
| `roomr.pen` | The Pencil source for the banner, the logo mark and the diagram art. Open it in [Pencil](https://pencil.dev) and export to `assets/`. (To be added: it needs to be created in the Pencil app.) |

The brand follows Fonoster's: `#181818` background, `#39E19E` accent, white type. Diagrams in the
docs are Mermaid, so they stay text, diff well and are readable by AI tools; only the banner is an
image.
